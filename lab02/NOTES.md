\# Конспект по Git



\## Рабочая папка

Это мои файлы на диске, которые я сейчас редактирую.



\## Индекс (Staging Area)

Это промежуточная зона. Сюда я добавляю файлы командой git add, чтобы подготовить их к сохранению.



\## Коммит

Это сохраненная версия проекта (снимок). Каждый коммит хранит историю изменений.



\## Разница Git и GitHub

Git - это программа для контроля версий, работает локально на пк. GitHub - сайт, облако, где можно хранить свои Git-репозитории и делиться ими.



\## Использованные команды

\- git status — показывает состояние файлов (измененные, добавленные, неотслеживаемые).

\- git diff — показывает изменения в рабочей папке, которые еще не добавлены в индекс.

\- git diff --staged — показывает изменения, которые уже добавлены в индекс и готовы к коммиту.



\## Ветки



Ветка — это отдельная линия разработки. Она позволяет вносить изменения, не затрагивая основную версию проекта (например, main).



Что происходит с веткой при новом коммите: указатель ветки сдвигается на новый коммит. История внутри этой ветки продолжается, а другие ветки остаются на своих местах.



Что делает слияние (merge): объединяет изменения из одной ветки в другую. Создается новый коммит слияния, в котором совмещаются истории обеих веток.
